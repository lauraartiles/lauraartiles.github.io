Good Jar iOS Application

Description

Good Jar is a native iPhone habit tracker that turns completed habits into tokens users can exchange for personal rewards. Built with SwiftUI and SwiftData, it supports schedules, flexible weekly goals, streaks, history, reward claiming, onboarding, configurable week boundaries, and local-only persistence without requiring an account.

Tools Used

  • SwiftUI
  • SwiftData
